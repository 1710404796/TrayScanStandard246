# TrayScanStandard 项目流程文档

## 1. 项目目标与主链路

本项目是一个基于 WPF 的整盘扫码系统，核心业务链路为：

1. PLC/Modbus 发起扫码触发
2. 设备相机执行拍照
3. 算法服务执行解码
4. 结果按通道整理并回传 WCS（Socket）
5. 日志与数据帧落库/落盘

对应主执行路径（当前线上主路径）：

`MainViewModel -> InitMeCommand -> PlcModbusHealthService(MonitorLoop) -> DetectCCDCommand -> CamCaptureCommand -> VMWebAIClient.DetectCodesV1Async -> WcsTrayScanStandardServer.SendResult`


## 2. 系统启动与任务发起

### 2.1 启动入口

- `App.xaml.cs`
  - 创建 `Host`，注册 DI、MediatR、EF Core、Quartz、WebHost 等。
  - 启动本地 Web API（端口 `18080`）。
  - 启动外部算法进程 `vmapi\\LinxUniverse.VM.Webapi.exe`。
  - 启动 `Host.Start()`。

### 2.2 初始化触发

- `ViewModel/MainViewModel.cs`
  - 构造函数中异步发送 `InitMeCommand`。

- `Mediator/Handlers/InitMeCommandHandler.cs`
  - 初始化目录：`DataFrame` / `InsertLog` / `Data2D`
  - 初始化角色和权限表
  - 初始化相机：`ScanCameraService.Init()`
  - 初始化光源（CST/Wordop）
  - 初始化算法（VMWebAIClient）
  - 初始化 S7 PLC 任务服务：`pLCTaskService.Init(...)`
  - 启动 Modbus 监控：`plcModbusHealthService.StartMonitoring(...)`
  - 初始化 WCS Socket 服务（通过构造注入触发）


## 3. PLC -> 扫码 -> 解码 -> 传输 调用链（详细）

### 3.1 PLC 发起任务（当前实际触发为 Modbus）

- `Service/PlcModbusHealthService.cs`
  - 循环连接 `MainStorage.Saves.PlcIp:502`
  - 读取保持寄存器 `address=0`
  - 监听上升沿（`0 -> 1`）触发一次任务
  - 防重入：`SemaphoreSlim _jobLock`

### 3.2 设备扫码（拍照）

- `ExecuteCaptureAndUploadAsync` 内发送：
  - `DetectCCDCommand(MainStorage.SelectBattery)`

- `Mediator/Handlers/DetectCCDCommandHander.cs`
  - 根据 `ScanCameraService.MugenCameras + CameraSetting.Exposure` 组装 `CaptureInfo[]`
  - 发送 `CamCaptureCommand`

- `Mediator/Handlers/CamCaptureCommandHandler.cs`
  - 拍照前亮灯（Wordop）
  - 调用相机采集（逐曝光）
  - 拍照后灭灯（Wordop）
  - 返回 `Image2DResult[]`

### 3.3 解码

- `DetectCCDCommandHander`
  - 将拍摄图像写入 `Data2D`
  - 调用 `IVMWebAIClient.DetectCodesV1Async(imagePath, rois)` 解码
  - 多相机结果合并、按 `Index` 去重，生成 `DetectResult(Arr<CodeInfo>)`
  - 更新界面图像与工位临时状态
  - 发送 `SaveDataFrameCommand` 保存数据帧

### 3.4 传输到 WCS

- `PlcModbusHealthService`
  - 根据通道数构建 `CellCodeDateRequest`
  - 空码归一化为 `"null"`
  - 调用 `WcsTrayScanStandardServer.SendResult(payload)`

- `Service/WcsTrayScanStandardServer.cs`
  - 通过数据 Socket 发送 JSON
  - 双 Socket 结构：
    - 心跳 Socket：`WcsHeartPort`
    - 数据 Socket：`WcsDataPort`
  - 写入 `WcsLog`

### 3.5 心跳与状态

- `Jobs/HeartbeatJobs.cs`
  - Quartz 每 5 秒触发一次
  - 采集相机标识并发送心跳 `HeartbeatsRequest`


## 4. 任务调用方式（对外/对内）

### 4.1 对内命令（MediatR）

- 初始化：`InitMeCommand`
- 主扫码：`DetectCCDCommand`
- 拍照：`CamCaptureCommand`
- 图像推送：`PushImgCommand`
- 数据帧落盘：`SaveDataFrameCommand`

### 4.2 对外触发接口

- `Apis/WcsController.cs`
  - `GET /CaptureImage`
  - 可直接触发一次 `DetectCCDCommand`，返回二维码字典（旁路触发，不是 Modbus 主链路）

### 4.3 对外传输方式

- Socket 主通道：
  - 心跳：`WcsTrayScanStandardServer.SendHeartbeat`
  - 结果：`WcsTrayScanStandardServer.SendResult`

- HTTP（另一套能力）：
  - `Service/WcsService.cs` 对接 `wcs/grabAction`、`wcs/materialOnline`、`wcs/grab` 等接口
  - 主要用于托盘/物料相关业务，不属于本次“整盘扫码回传”主链路

## 6. 架构说明

当前总体属于：`WPF + MVVM + MediatR(CQRS风格) + Service + EF Core + Quartz + Socket/HTTP 混合通信`

分层可概括为：

1. 展示层：`View/*`、`ViewModel/*`
2. 应用层：`Mediator/Commands`、`Mediator/Handlers`、`Mediator/Queries`
3. 领域/模型层：`Models/*`、`Service/Models/*`
4. 基础设施层：`Service/*`（相机、PLC、WCS、光源）、`Data/*`（EF Core）


## 7. 主要模块与已完成功能

### 7.1 PLC/触发模块

- `PlcModbusHealthService`
  - PLC 连通性监控
  - 触发信号轮询
  - 上升沿触发与并发保护
  - 解码重试（`DecodeRetryTimes`）

### 7.2 相机与光源模块

- `ScanCameraService`
  - 相机初始化、重连、状态监控
  - 多相机配置管理

- `CamCaptureCommandHandler` + `WordopLightService/CST`
  - 拍照前后光源联动
  - 多曝光采集

### 7.3 解码模块

- `DetectCCDCommandHander`
  - 图像保存
  - ROI 解码
  - 通道结果合并去重
  - UI 同步与数据帧落盘

### 7.4 传输与日志模块

- `WcsTrayScanStandardServer`
  - 双 Socket 自动重连
  - 心跳+数据发送
  - WCS 日志落库

- `HeartbeatJobs`
  - 周期心跳

- `LinxContext`
  - `WcsLogs`、`PalletLogs`、`WarningLogs`、`BatteryTypeInfos` 持久化


## 8. 疑似多余/未接入主流程代码（建议复核）

以下为“从代码可见的疑似冗余”，建议由业务负责人二次确认后再清理：

1. `Mediator/Commands/CCD/StartDelectTaskCommand.cs`
   - 仅有命令定义，未找到对应 Handler。
   - `PLC/Tasks/ScanTheCodeTask.cs`、`ScanEndTask.cs` 调用它，但实际没有执行落点。

2. `PLC/Tasks/ScanTheCodeTask.cs` / `PLC/Tasks/ScanEndTask.cs`
   - 任务内容仅发送 `StartDelectTaskCommand`，核心业务已转到 `PlcModbusHealthService`。
   - 当前看更像历史 S7 任务链路残留。

3. `PLC/TrayScanStandardCCDContext.cs`
   - 多个接口属性 `throw new NotImplementedException()`（`CodeDelectDB` 等）。
   - `Loop()` 中 `return Task.CompletedTask;` 后仍有不可达 `throw`。

4. `Methods/WcsMethods.cs`
   - 空静态类，无实际业务实现。

5. `Startup.cs` 中 `HomeController`
   - 非标准 MVC Controller（无继承 `ControllerBase`、无 `ApiController`），功能非常弱，仅返回字符串。
   - 更像模板残留。

6. `Service/WcsService.cs` 的 `[Obsolete] SendRequestAsync<T>`
   - 已标记过时，且现主流程主要使用 `LogMiddleWare`/`SendRequest` 或 Socket。

7. `TrayScanStandard.csproj` 中 `test.sol` 与初始化中读取 `solution.sol`
   - 文件命名存在不一致风险，可能导致部署后算法加载文件混乱（需核对是否由外部下发 `solution.sol`）。


## 9. 当前主流程结论（可直接用于对外说明）

1. 任务由 PLC Modbus 信号上升沿触发；
2. 系统通过多相机多曝光采图；
3. 调用 VM 算法服务按 ROI 解码；
4. 合并各通道条码并补全空位；
5. 通过 WCS 数据 Socket 回传 `CellCodeDateRequest`；
6. 同步进行心跳上报、日志入库、数据帧归档。
